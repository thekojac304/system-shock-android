2. HAZE IMPLEMENTATION
The generated world fragment shader packs camera-to-fragment world distance
into the existing RGBA world target's unused alpha channel, normalized over
24 world units. The world clear alpha is zero. The existing post source copy
preserves alpha, so the post shader obtains distance per pixel without an
additional render target, draw, depth readback, or world/UI composition change.
The post shader uses smoothstep(start,end,distance) and a bounded colored mix.
Clear/background pixels have no haze. GPU GENERATED lighting remains the RGB
source; the post output is still composed before HUD, menus, and touch controls.
The 8-bit packed distance has about 0.094 world-unit quantization; the broad
smooth curve hides it in the reviewed views. This is atmospheric perspective,
not volumetric scattering or a fog wall.

3. DISTANCE DESATURATION
The same distance factor blends a small fraction of the graded color toward
its luminance. Medical far maximum is 7%; Executive far maximum is 5%.
Near pixels retain the existing archetype's saturation. FX BASE and HAZE
exclude this term; FX DIST and FULL include it.

4. DISTANCE CONTRAST
After tone shaping, a far-only contrast reduction uses a 0.25 pivot. Medical
maximum is 3%; Executive maximum is 2.5%. It gently lifts far dark values
without changing nearby black detail. It was tuned together with haze and
desaturation; the three are intentionally modest and share one distance curve.

5. SHADOW / BLACK TINT
A separate archetype shadow-bias RGB term is multiplied by luminance and a
shadow weight (1-smoothstep(.12,.62,luminance)). Pure black therefore stays
black, near-black texture structure remains, and highlights/fixture colors
receive little or no bias. The original MED A and EXEC A shadow/highlight
grades are retained. FX FULL alone adds the new shadow bias.

6. BLOOM DECISION
SKIPPED. Reviewed emissive masks are available inside the world shader, but
the composed world target holds RGB plus the newly packed distance in alpha.
It has no separate emissive-only image for blur. A correct bloom path would
require another attachment or selective draw, a low-resolution source, blur,
composite, and matching resource/fallback handling. A brightness threshold
would incorrectly glow ordinary bright palette art. This optional work was
not worth expanding the renderer in this phase. No bloom toggle is exposed.

7. ANIMATED GRADE DRIFT
FX FULL applies a sinusoidal shadow-only multiplier bounded by each preset's
strength. Its time comes from saved game_time / CIT_CYCLE, which stops on pause
and is capped by the game's existing simulation delta handling after resume.
There is no wall-clock catch-up flash. The shader still grades only the world.
Medical period 18 s, amplitude +/-0.004; Executive 26 s, +/-0.003. It is not
a fixture event or gameplay light.
