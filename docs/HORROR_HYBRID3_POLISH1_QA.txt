2. HIGHLIGHT SHOULDER
The prior grade's .68 high-value shoulder remains. A new high-only, monotone
rolloff begins at .64 after the previous curve, using excess /
(1 + 2 * rolloff * excess). Executive Auto rolloff is .55; Medical is zero.
Midtones below .64 are untouched by this stage. Executive's already-reviewed
emissive mask pixels also use .88 intensity, so texture variation reaches the
8-bit target before it can clip. Global exposure remains 1.02.

3. MIDTONE LIFT
Executive Auto adds .030 only in a luminance window: smoothstep(.03,.16,Y)
times (1 - smoothstep(.36,.68,Y)). It fades out at black and in highlights.
Medical lift is zero. This is a small structural lift, not a deck-wide exposure
change.

4. NEAR-BLACK PRESERVATION
After the previous toe/shoulder, Executive Auto multiplies channels by
1 + .08 * (1 - smoothstep(.02,.16,channel)). Zero remains exactly zero and
the adjustment vanishes above .16. Medical preservation is zero, retaining
the accepted Medical curve.

5. EMISSIVE / GENERATED-LIGHT MULTIPLIERS
Generated world shading uses a per-preset emissive multiplier only where the
reviewed material mask row marks a self-lit pixel. Executive Auto is .88;
Medical Auto is 1.00. Ordinary bright unmasked pixels and unreviewed unlit
objects receive no new scale. Existing source-tile flicker still multiplies
the reviewed source. Generated local-light contribution is multiplied after
profile intensity and flicker: Executive Auto 1.05, Medical Auto 1.00. No
source position, receiver, or geometry is changed. Post Off and post failure
use 1.00 multipliers. Older presets' zero-initialized new fields resolve to
neutral 1.00.

6. SPLIT TONING
The existing shadow and highlight weighted tint stages already implement
split toning. They remain separate; Executive Auto shadow tint is
(.85,.91,1.02) at .10 and highlight tint (1.07,1.01,.89) at .08. The added
Executive shadow bias was reduced from (.015,-.010,.012) to
(.005,-.010,.012), avoiding an over-warm dark region. Medical cool shadows
and neutral/cool highlights are unchanged. This is a refinement of the
existing split, not a new global color filter.

7. BLOOM DECISION / SOURCE ARCHITECTURE
SKIPPED. The reviewed mask is available inside the world fragment shader, but
the SDL-owned RGBA8 world target stores composed RGB and packed distance in
alpha. There is no clean emissive-only image to blur. A correct path would add
an MRT attachment or selective pass, then downsample, blur, composite, and
resource/fallback handling around SDL target binds. That is disproportionate
to this bounded pass. Broad luminance thresholding would make ordinary white
textures bloom and was rejected. No buffer, toggle, or halo is claimed.

8. HEIGHT FOG
The normal world fragment pass computes world-space low-height weight below
1.55 units over a .9-unit falloff and multiplies it by the existing camera
distance interval 2..10 units. Executive Auto uses density .045, cap .04,
and muted neutral color (.45,.42,.39). It mixes into world RGB before the
post stage. Medical density is zero. It adds no FBO, texture, depth readback,
or draw. The existing distance haze remains independently active. Height fog
is enabled only for generated + post + FX FULL; if post has failed, subsequent
world submissions use zero fog. Invalid/zero falloff or density is neutral.

9. LOCAL FOG VOLUMES / HEAT HOOK
SKIPPED both. Manually placed volumes and future heat distortion would add
new controls and authoring without improving the reviewed views in this pass.
