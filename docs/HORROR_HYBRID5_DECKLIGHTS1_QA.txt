fallback remain intact. Runtime acceptance now uses a count-driven table of

comparisons; no new profile asset was packaged.

images are usable original gameplay views. The same sky/stars fallback was
observed at one Research spawn and the Flight hangar view; their indoor
representative views use the Enhanced path. No renderer/sky support was added
to chase Grove coverage. If future playtesting finds enclosed Grove views
without that fallback, the Grove row is ready for the existing post path.
