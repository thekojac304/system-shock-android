2. OVERLAY DESIGN
The QA application (RP5NP_QA_TOOLS build) shows two translucent MODE and POST
buttons in the left 4:3 side bar during unpaused gameplay. Bounds use fractions
of the actual Android output surface and scale with orientation/resolution.
The ordinary release build never enables the comparison overlay. Buttons are
fixed QA controls, independent of the touch layout editor and preference file.
The existing touch bitmap font, colors, alpha blending and render-state restore
are reused. The gameplay world and black bars retain their existing layout.

3. MODE CYCLE
ORIGINAL -> VIS1B HORROR -> GPU PROOF -> GPU GENERATED -> ORIGINAL.
If the Video menu leaves VIS1 CONSERVATIVE selected, the next QA tap enters
VIS1B HORROR. The button calls horror_visuals_set_mode, the Video menu's
existing setter; this saves the same world-visuals preference and invokes the
existing GPU mode-change hook. No menu redraw or pause path is called.

4. POST CYCLE
Medical: OFF -> AUTO -> MED A -> MED B -> MED C -> OFF.
Executive: OFF -> AUTO -> EXEC A -> EXEC B -> EXEC C -> OFF.
Other levels: OFF -> AUTO -> OFF (neutral/default behavior).
The button reads and updates the same gShockPrefs.postEnabled/postChoice fields
used by Video -> Hybrid Post and calls SavePrefs. It does not introduce another
post state or preference key. Cross-deck choices enter the current deck's first
preset on the next tap. Vignette and grain preferences remain untouched.

5. TOUCH OWNERSHIP AND STATUS
QA button hit testing occurs on raw output-surface coordinates before gameplay
role selection. A claimed finger never becomes move/look/fire/use/cursor/ammo;
release outside its button or movement beyond tap slop cancels the action.
The bridge also skips its pre-touch mouselook request for these buttons.
Commands are applied after input polling, only while normal gameplay remains
available. The visible label derives from current preference values and the
current deck on every sync, including after menu changes. It lasts 1.6 seconds
and fades over the last 350 ms without pausing or a center-screen panel.
