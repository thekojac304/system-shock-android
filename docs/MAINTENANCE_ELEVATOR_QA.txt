NORMAL VS QA ARRIVAL
Normal elevator arrival and QA travel both call trap_teleport_func, which calls
go_to_different_level. That path stores inventory, writes the old deck, loads
the destination, restores inventory/art/physics, advances destination schedules,
runs level-entry triggers and moves the player through obj_move_to.

The elevator additionally closes its MFD panel reference before travel, uses
the fixture's destination-panel table to preserve player offset, repositions
at the destination panel, runs the elevator janitor and opens the arrival door.
QA instead validates an empty flat tile from CurrentGame and places the player
there at standing height; it does not perform those elevator-specific steps.
The QA selector checks all 64x64 terrain tiles, requires standing clearance
and a same-height exit, and prefers open tiles nearest the map center.
The logs now record panel reference, player physics handle and score state at
the same transition stages so stale QA state can be distinguished from an
elevator or music failure rather than presumed to be the cause.

MUSIC OWNERSHIP
Remake music selects a deck, including its elevator tiles. The physics path
still changes stock music zones: compare_locs -> fade_into_location ->
load_score_guts(7) for ELEVATOR_ZONE. A stock theme load invokes StopTheMusic,
which suspends the external stream and restores the synth hook. The next
eligible music-AI update resumes the existing same-deck decoder; a deck change
stops/frees the old stream and selects the new deck's track. StartTrack refuses
stock MIDI playback while external music owns the stream. The old level-change
MacTuneQueueTune calls are stubs in this Shockolate implementation.
